# Kermo — релізи

Kermo — це пульт для **власного** комп'ютера з телефона: медіа, гучність, живлення
(вимкнути, сон, перезапуск), трансляція екрана, файли між ПК і телефоном, віджети.
Тут лежать лише готові збірки; кожен реліз містить:

| Файл | Що це |
|---|---|
| `Kermo-x.y.z-setup.exe` | програма для Windows 10/11 (інсталятор) |
| `Kermo-x.y.z.apk` | застосунок для Android |
| `desktop.json`, `android.json` | службові файли автооновлення (підписані) |

Завантажити: **[останній реліз](https://github.com/ifoxp/kermo-releases/releases/latest)**.

## Що програма робить на ПК

Щоб не було сюрпризів, чесно про все, що може насторожити антивірус:

- **Автозапуск.** Kermo запускається разом з Windows, щоб телефон міг керувати ПК. Запит на
  права адміністратора з'являється один раз, на першому запуску, і лише після твого «так».
- **З'єднання з сервером Kermo.** Поки до ПК не підключено жодного телефона, програма ні з ким
  не з'єднується. Після спарювання вона тримає одне з'єднання із сервером Kermo, щоб телефон
  міг дістатися ПК поза домом. Удома телефон з'єднується з ПК напряму, через локальну мережу.
- **Команди з телефона.** Виконуються лише команди від телефонів, які ти сам додав
  на ПК (QR-код + підтвердження коду на обох екранах), і лише в межах рівня доступу,
  який ти їм дав. Відкликати телефон можна будь-коли в розділі «Пристрої».
- **Значок у треї** показує, коли телефон керує ПК; журнал дій — у вікні Kermo.

## Попередження Windows

Інсталятор не підписаний платним сертифікатом, тому Windows SmartScreen може показати
«Windows захистила ваш комп'ютер». Натисни «Докладніше» → «Виконати все одно».
Окремі антивіруси інколи помилково позначають такі програми; якщо це сталося — напиши в
[Issues](https://github.com/ifoxp/kermo-releases/issues).

## Перевірка файлу

SHA-256 кожного файлу є в `android.json` (APK) і на сторінці релізу. У PowerShell:

```powershell
Get-FileHash .\Kermo-x.y.z-setup.exe -Algorithm SHA256
```

Оновлення програма ставить сама й перевіряє їхній підпис перед встановленням.
